# QA-Gate – Framework de Reporte Assistido

## Reduzindo o MTTR (Mean Time To Repair) através da tradução inteligente de feedbacks de usuários leigos para documentação técnica de QA.

### O Problema (O "Gap")
Explique que o projeto nasceu da observação no dia a dia do suporte (como na sua experiência na Linx).  

Cenário Atual: Chamados vagos como "não funciona", que geram "pingue-pongue" entre suporte e desenvolvimento.

Impacto: Perda de tempo, aumento de custos e frustração do cliente final.

### A Solucao Técnica
Destaque os diferenciais que incluímos nos Requisitos do Sistema:  

Captura Automática de Contexto: Extração de metadados como UserAgent, URL e resolução de tela.  

Módulo de Breadcrumbs: Rastreio das últimas 5 interações do usuário para reprodução fiel do bug.  

Conversor Gherkin: Transformação do relato simples em estrutura "Dado que / Quando / Então".  

###  Impacto de Negócio e Social
Shift-Left Testing: Trazer a qualidade para o início do processo, evitando que bugs mal reportados cheguem à produção.  

Inclusão Digital: Interface amigável para usuários com baixo letramento digital, garantindo que suas dores sejam ouvidas tecnicamente.
